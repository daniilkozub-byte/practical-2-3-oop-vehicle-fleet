## Загальна постановка задачі

Розробити консольний Java-застосунок для обліку військової техніки підрозділу.

Програма повинна дозволяти створювати різні типи техніки, зберігати інформацію про неї, виконувати службові операції та працювати з усіма типами техніки через спільний базовий тип.

> **Важливо:** усі етапи виконуються в одному проєкті. Кожен наступний етап розширює програму, створену на попередньому. Не створюйте окрему програму для кожної теми.

Повний покроковий опис усіх 11 етапів + фінального етапу — у **[docs/ROADMAP.md](docs/ROADMAP.md)**.

## Структура репозиторію

```text
practical-2-3-oop-vehicle-fleet/
├── README.md                 — цей файл
├── docs/
│   └── ROADMAP.md             — детальний Road Map (Етапи 1-11 + фінальний етап)
├── pom.xml                    — Maven-конфігурація проєкту
├── .gitignore
└── src/main/java/ua/mil/vehicles/
    ├── Main.java               — точка входу, демонстрація роботи системи
    ├── Vehicle.java             — базовий абстрактний клас
    ├── TransportVehicle.java    — транспортний засіб
    ├── ArmoredVehicle.java      — бронетехніка
    ├── SpecialVehicle.java      — спецтехніка
    └── VehicleFleet.java        — автопарк підрозділу
```

У `src/` вже підготовлено каркас класів з `TODO`-коментарями, прив'язаними до відповідного етапу з `docs/ROADMAP.md`. Це орієнтир по структурі — самі методи потрібно реалізувати самостійно.

## Як почати роботу

1. Склонуйте репозиторій:

   ```bash
   git clone <URL-репозиторію>
   ```

2. Відкрийте проєкт в IDE (IntelliJ IDEA / Eclipse / VS Code) як Maven-проєкт.
3. Рухайтесь по етапах з `docs/ROADMAP.md` послідовно, заповнюючи `TODO` у відповідних класах.
4. Після кожного етапу перевіряйте роботу через `Main.java`.

Збірка та запуск через Maven:

```bash
mvn compile
mvn exec:java -Dexec.mainClass="ua.mil.vehicles.Main"
```
